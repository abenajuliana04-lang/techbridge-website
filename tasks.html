30-Day Practical Internship

Eight tasks, one steady climb from beginner to advanced

This is the Web Development track of the TechBridge internship: eight practical, project-based tasks spread across 30 days. Tap a task to see what it involves.

DAY 1Beginner
Task 1 — Build the TechBridge Homepage
⌄

Create the first version of the TechBridge website using HTML and CSS — brand identity, program overview, and the application call-to-action.

DAY 4Beginner
Task 2 — Build the TechBridge Programs Experience
⌄

Create a dedicated Programs experience presenting TechBridge's Data Analytics and Web Development tracks side by side.

DAY 8Beginner → Intermediate
Task 3 — Build the Internship Tasks Experience
⌄

Build the page you're looking at right now — an interface that lays out the internship journey so a new intern can see what's ahead.

DAY 11Beginner → Intermediate
Task 4 — Build an Interactive Task Tracker
⌄

Use JavaScript to let visitors switch between the Data Analytics and Web Development tracks without reloading the page.

DAY 15Intermediate
Task 5 — Build the Intern Registration Experience
⌄

Design a professional registration and onboarding interface for new TechBridge interns.

DAY 19Intermediate
Task 6 — Build the Task Submission System
⌄

Create an interface through which interns can prepare and submit their task work for review.

DAY 22Intermediate
Task 7 — Build the Intern Dashboard
⌄

Build a dashboard where an intern can view their profile, progress, tasks, and submissions in one place.

DAY 26Intermediate
Task 8 — Build the Complete TechBridge Internship Platform
⌄

Bring every component built during the internship together into one complete TechBridge platform.
